- `hint` 对四个退回原因是同一句安装提示（规格要求返回通用子代理时附安装提示），对 `shadowed` / `project-agent` 安装并不改变结果。
- 冻结内容读不到的旧任务，退回边不豁免任何技能（失败关闭，不放宽门禁）。
- worktree 任务在 build-complete 之后往工作区写入未声明的文件，复核会得 `revision-stale`，与 in-place 同口径。
- 升级前手工设过 `isolation=worktree` 且带 git 令牌的任务，升级后复核得 `isolation-mismatch`，回 Build 重新捕获（已写入 CONTRACT）。
