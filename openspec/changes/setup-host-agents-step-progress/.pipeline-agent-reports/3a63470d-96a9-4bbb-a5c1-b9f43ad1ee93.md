## 发现清单

- **low**：`hooks/step-progress.sh:32` 的名字正则只收小写字母、数字和连字符，而 `task-worktree.ts:43` 和 `task-worktree-list.ts:27` 允许大写与下划线。含大写或下划线的任务流转后静默不打印清单。修法：对齐字符集，或在文档里写明限制。
- **low**：`packages/kernel/src/workspace/fingerprint.ts:395-398` 与 `host-local.ts` 的 `skipUntrackedHostLocalDirs`。完整指纹现在跳过未跟踪的 `.claude/worktrees/`，已有该目录的项目升级后既有 build revision 与评审结论会 stale。修法：在升级说明里写明。
- **low**：`packages/kernel/src/infrastructure/host-agent-install.ts:259-263`。卸载时对清单 `lstat` 的非 ENOENT 错误（例如 EACCES）被吞掉，由后面读清单兜底。修法：直接上报该错误。
- **low**：`packages/kernel/src/workspace/task-worktree-list.ts:95`。`inside.startsWith('..')` 会把名为 `..foo` 的合法子目录误判为越界。任务名正则不允许 `.`，实际不触发。修法：改判 `inside === '..'` 或 `'..' + sep` 前缀。
- **low**：`packages/kernel/src/workspace/task-worktree.ts:126-149`。路径与分支检查和 `git worktree add` 之间有 TOCTOU 窗口。同名并发创建失败时，回滚可能清掉另一个创建者刚建出的同名目录和分支。修法（可选）：建前先建占位锁。
