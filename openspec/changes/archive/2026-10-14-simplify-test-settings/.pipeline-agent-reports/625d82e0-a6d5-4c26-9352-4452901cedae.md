## 三、发现

1. **low，hook 范围比规格逐字多。** `trust-command.sh` 另外拒绝 agent 设置 `TENON_RUNTIME_HOME`、`TENON_RUNTIME_ROOTS`，以及 tenon 调用前改 `HOME` 或 `XDG_STATE_HOME`。
   - 我判断这属于"信任只能由用户本人确认"的纵深防御，不算多做：信任存储的根目录由这些变量决定，不拦的话 `test-trust/` 的写入拒绝可以绕过。
   - 建议在 R11 末条补一句"hook 同时拒绝 agent 改写状态目录的根变量"，使规格与实现逐字对上。
2. **low，规格对 `tenon test trust --status` 没有说明。** 实现里 `--status` 不算信任决定，放行；规格只说"hook 拒绝 agent 运行 `tenon test trust`"。这是合理的只读例外，建议规格补一句。
