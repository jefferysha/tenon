# PRD · 技能画布连线

## 问题（截图 25 / 26）
1. 起点 / 终点到节点的线是弯的：端口节点按常量高度居中，字号放大后节点实际更高，端口错位。
2. 多个并行节点到下一步是多对多斜线；用户要求并行波先在中线汇合，再一条线连到下一步。

## 目标
- `layoutSkills` 各波次围绕同一条中线纵向居中（最高的一列决定高度）。
- 端口 / 汇合点 y 用 React Flow 测得的节点高度计算，退回常量 60。
- 相邻两波若构成完整的列依赖（下一波每个节点都恰好依赖上一波全部节点），渲染改为：上一波所有节点 → 汇合点（无箭头）→ 下一波每个节点（带箭头、脉冲）；否则保持直接边。起点 / 终点即首尾汇合点。
- 单节点对单节点时线为直线（端口同高）。

## 验收
- [ ] `layoutSkills([1,3,1])` 三列中心 y 相同。
- [ ] 渲染边包含 `j0->…` 汇合边，且不再包含被替代的直接边；`data-edges` 仍 = depends_on 数。
- [ ] web 用例、design-scale、comments、build 通过。
