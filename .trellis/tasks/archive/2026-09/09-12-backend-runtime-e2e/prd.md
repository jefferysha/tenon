# 真实后端任务运行验证

## Goal

在隔离临时项目中启动真实 Tenon 后端，创建并运行一个任务，验证状态推进、门禁结果以及运行日志和运行时产物查询接口。

## Constraints

- 使用真实构建后的 server/CLI，不使用 mock API。
- 使用临时项目和临时 change，不修改现有项目或用户 workflow。
- 保存命令输出、HTTP 响应和清理结果。

## Acceptance criteria

1. 后端服务真实启动并响应健康/项目接口。
2. CLI 能真实创建临时任务并读取状态。
3. 任务真实执行或在治理门禁处返回明确、可复现的阻断原因。
4. 能查询任务阶段、运行记录和运行时产物接口；没有产物时不得伪造产物。
5. 测试结束后临时目录和测试 workflow 被清理。
6. 交付证据日志和结论，区分通过、阻断和环境限制。
