# PRD · 工作流页修复二

## 问题（用户截图 23 / 24）
1. 技能编辑器添加技能没有预览动画；只能并行添加（新节点无依赖），无法串行。
2. 起点 / 终点的空心圆 + 虚线边难看。
3. 整个 dashboard 字体偏小，要放大 20%。

## 目标
- 拖放预览：拖到画布上出现幽灵节点与预览边，落点决定语义——落在某一波的列上 = 并入该波（并行）；落在末列右侧 = 新的一步（串行，依赖末波全部技能）；落在首列左侧 = 新的第一步（首波全部技能依赖它）。技能库「+」= 串行追加。新节点入场动画（缩放 + 淡入，reduced-motion 不动）。
- 起点 / 终点：实心小点（起点强调色、终点灰）+ 下方一字标签；起终点边实线不闪、不带箭头进终点。
- `@theme static` 排版刻度整体 ×1.2：micro 13 / caption 14 / body 16 / base 17 / title 19 / section 24 / page 34，行高同比。7 档不变。

## 验收
- [ ] `addSkillAt` / `dropTargetFor` 纯函数测试：join / after / before 三种语义正确改写 depends_on。
- [ ] 编辑器点「+」后新节点依赖末波（data-edges +1），首个技能时无依赖。
- [ ] `flow-start` / `flow-end` 含文字「起点」「终点」。
- [ ] index.css 刻度值更新，`check:design-scale` 通过；web 全部用例通过；build 通过。
