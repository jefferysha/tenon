# 用户已定 UI 偏好（v0.3 版，派发给所有前端 worker；冲突时停下报告，不得自行取舍）

沿用：
- 零废话：页面上除错误外不写句子，说明进 Tooltip；一词一概念；名称只显示一个（有 label 显示 label，否则 id）。
- 任何地方不得换行（nowrap + 截断 + title）。
- 动作放在对象旁，不要底部动作清单。
- 工作流页两栏：左栏工作流名 + ⋯ + 轨道页签 + 编号纵向流程（顶部「总览」行）；右栏 输入 → 技能 → 输出 → 门禁（技能画布内用泳道放执行者/技能/测试/评审者；退回与测试策略在门禁段）。
- 输入/输出为带表头的表（文件 · 来源阶段 · 来源技能）。
- 画布用 React Flow；起点/终点为实心圆点。
- 门禁只有 评审 / 自动。
- 单一深绿强调色 + 暖灰；字号刻度 13/14/16/17/19/24/34；token 在 packages/dashboard-app/src/index.css。
- 否决过的：卡片堆叠、药丸（计数徽标/头像/状态点除外）、菱形门禁行、站点图、点阵画布用于阶段列表、来源用方框芯片、段头换行、空心圆起终点。
- 路径选择用系统文件夹选择器；智能体与测试的登记在终端，Dashboard 只展示与编辑配置；Dashboard 不调模型。

2026-09-30 用户批准的变更（按 design-audit.md）：
1. 流动动画改为「Signal」：一条恒速传送带贯穿全图（按到达距离计算相位，分叉/汇合天然同步），4 层彗星（核 10px、拖尾 26/48px、光晕 72px），空闲为慢速环境流（140px/s、×0.7 透明度），运行中从当前节点向终点（300px/s）；已完成线为强调色实线、未来线中性；评审门处彗星停住、环变琥珀，自动门闪一下通过；节点到达时边框+光晕约 600ms 衰减；单一时钟、只写热边、离屏/隐藏暂停；减少动态效果时只保留静态高亮。仍然是「从起点到终点持续流动」，但不再是短虚线段。
2. 总览节点视觉 32px，点击热区 40px。
3. 阶段条「已完成」改为暖灰，只有「当前」用强调色；阻塞时不呼吸。
4. 阶段列去掉边框，改为标题行 + 4% 色带，高度贴内容；空泳道只读时隐藏。
5. 技能名等改用常规字体（Inter 500），等宽只用于 id、路径、命令、哈希；长名按整段缩短（保留首段与末段，如 test…development），完整名在 Tooltip；总览节点宽 208px。
6. 连线：平滑直角、圆角 8px、对比度 ≥ 3:1（--flow-line）、去掉每跳箭头只在汇入处保留一个；节点 40px 高，左侧状态符号。
