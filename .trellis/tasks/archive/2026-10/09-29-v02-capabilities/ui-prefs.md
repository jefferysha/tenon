# 用户已定 UI 偏好（原文要点，不得违反；冲突时停下报告，不得自行取舍）
- 零废话：页面上除错误信息外不写句子，说明放 Tooltip；一词一概念（阶段/技能/输入/输出/门禁/轨道/工作流/客户端）；名称只显示一个（有 label 显示 label，否则 id，前端不翻译）。
- 任何地方不得换行（筛选标签、芯片、卡片标签、按钮一律 nowrap / 截断 + title）。
- 动作放在对象旁，不要底部动作清单。
- 工作流页两栏：左栏工作流名 + ⋯ 菜单 + 轨道页签 + 编号纵向流程（块只有名称与门禁图标，回流为右侧虚线弧）；右栏顺序 输入 → 技能 → 输出 → 门禁，段头一行（标题 · 计数 · 动作）；输入/输出为等分带表头的表（文件 · 来源阶段 · 来源技能），不显示读取阶段，不出现「契约」和 emoji。
- 技能用 React Flow 画布；技能编辑浮层：左本机技能库（点行预览 SKILL.md + 「加入」按钮），右画布拖拽编排并行/串行，拉线 = depends_on。
- 脉冲：GSAP 从起点到终点依次传递、持续循环（空闲画布也循环，不得改成只在运行时播）；起点/终点为实心圆点。
- 门禁只有两种：评审 / 自动。
- 字号刻度 13/14/16/17/19/24/34；单一深绿强调色 + 暖灰；原型为视觉基准；token 见 packages/dashboard-app/src/index.css。
- 用户反复否决：卡片堆叠、药丸（计数徽标/头像/状态点除外）、菱形门禁行、站点图、点阵画布用于阶段列表、来源用方框芯片、段头换行、空心圆起终点。
- 选择路径一律用系统文件夹选择器，不用手输长输入框。
- 只做明说需要的，一切从简，删功能优于堆功能。
