# 表单与页面补全

## 需求
- R1 新建工作流：选择起点（空白 / 复制内建 default / simple / 已有工作流），名称，OpenSpec 开关；右侧预览阶段列表；校验名称唯一与合法。
- R2 新建/编辑模板：表单字段（名称、分类、适用框架多选）+ Markdown 正文编辑器（编辑 / 渲染切换）+ 占位变量说明（Tooltip）；校验。
- R3 测试方向改名「测试模板」，按 runner 结构化只读展示（配合 v02-test-system），不再显示 YAML 原文；复制命令。
- R4 技能页「引用」列包含 OpenSpec 注入与 manifest 叠加的技能（用 v02-orchestration 的内核投影）。
- R5 设计资源落地：新建项目向导增加「资源」步骤（可选 shadcn、Lucide、DESIGN.md 种子等），创建时调用 `POST /api/design/seed` 写入；默认前端轨道提示词指向 `tenon resources`。
- R6 新建类对话框统一：固定高度、Enter 提交、Esc 关闭（有输入时二次确认）、字段下方即时校验、说明进 Tooltip。

## 验收
每个表单有组件测试（字段、校验、提交载荷）；浏览器走查截图；遵守 UI 规则。

## 走查补充（2026-09-29，主线程浏览器验收）
- R7 资源步骤与模板步骤同构：点行在右侧预览（说明、许可证、链接、将写入项目的内容），预览头部「加入 / 移除」；列表按上一步所选模板的框架过滤（例如选了 React 只列 React 可用的组件库），可切「全部」。
- R8 新建工作流预览同时列出轨道（default 有 5 条），不只阶段。
