# Dashboard 精简重做：工作台 + 工作流

## Goal

只保留用户需要的两页，其余全部删除。用户原话：「我只需要获取到每个阶段的输入和输出，产出物可以阅读，
其他都是不需要的功能」「功能是全部只做需要的，一切从简，整个系统的 UI 都是」。

## Scope

### 顶部条
logo · 面包屑「工作空间 / 当前页」· 项目切换 · 两个标签（工作台 / 工作流）· 搜索 · 连接状态 · 主题/语言。
自动化、机器标签删除，对应代码（afk/、machine/、hostPlan/ 页面层）删除。

### 工作台（按模板 1:1）
左列项目 → 中列任务（状态页签 + 搜索）→ 右列：任务名 / 状态 / 六段阶段轨 / **当前选中阶段的「输入 / 输出」文件列表**
/ 点击文件在下方预览卡里读内容 / 底部一句说明。
- 输入 = 该阶段在工作流定义里声明读取的字段对应的文件；输出 = 该阶段声明产出的字段对应的文件；
  再加上 OpenSpec 文档（proposal / design / tasks…）作为一组。
- 文件状态只有 可读 / 缺失。
- 读文件走新增只读接口 `GET /api/documents/read?root&path`，路径限定在已登记项目根内，256KB 上限，UTF-8。
- 没有技能 / 计划 / 终端 / 记录 sheet；没有写操作。

### 工作流
左列：工作流列表（default 标只读），每项下一行小字列出使用它的轨道。底部：新建 / 复制 / 删除。
中列：阶段顺序（上移 / 下移 / 删除 / 末尾添加）。
右列（选中阶段）只有三段，不用页签：
1. 技能：本阶段技能列表，每个技能标「串行 / 并行」（并行 = 与上一技能同波，由 depends_on 推导），可添加 / 移除 / 切换串并行；
2. 门禁：无 / 评审 / 确认；
3. 输入 / 输出：自动推导，只读。
底部：未保存改动 → 放弃 / 保存。
删除：轨道面板、管线预览、工作流设置（策略 / 运行时 / 钩子 / 治理）、执行指令、阶段 hooks sheet、技能编排 Dialog 的库拖拽（改为简单的搜索选择列表）。

## Acceptance Criteria
- 顶部只有两个标签；自动化 / 机器相关源码与测试不存在。
- 工作台右列能对任意任务、任意阶段列出输入 / 输出文件并读出内容；缺失文件明确标出。
- 工作流页能完成：新建 / 复制 / 删除工作流；增删移阶段；增删技能并切换串并行；改门禁；保存。
- 每页右列没有页签或最多一组。
- typecheck / test:web / design-scale / comment-honesty / server 测试通过；375 与 1440 无横向滚动。

## Non-goals
不再保留任何「因为原来有」的功能；不做深色主题以外的视觉扩展。
